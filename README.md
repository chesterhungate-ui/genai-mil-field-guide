# genai.mil Field Guide

An unofficial, open-source prompt library and field guide to the four AI tools on a U.S. Army government computer: Microsoft Copilot, Gemini, Grok and ChatGPT Mil. It's written for marketing staff with little AI background. The views are the author's own. This is not a DoD or Army site.

Live page: https://chesterhungate-ui.github.io/genai-mil-field-guide/

Each version is one self-contained HTML file, with no build step and no external fonts, scripts or images.

## Versions

Prompt examples are notional. Don't paste classified information, PII or health information into any tool, and have a person check every output.
